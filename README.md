### Hi, I'm Yusuf

Software engineer from Turkey. These days I mostly build in Go — small
single-binary services, background workers (Redis / Asynq), and Postgres —
plus the self-hosted infra I run them on. Flutter/mobile is my day job.

I prefer small, readable tools over big frameworks, and I write up the
tradeoffs on my [blog](https://yusufihsangorgel.github.io).

A few things I've built:

- [queue-inspector-mcp](https://github.com/Yusufihsangorgel/queue-inspector-mcp) — an MCP server for inspecting Redis-backed job queues (Asynq / BullMQ), read-only by default.
- [go-multitenant-gateway](https://github.com/Yusufihsangorgel/go-multitenant-gateway) — a single-binary multi-tenant API gateway in Go.
- [redis_task_queue](https://github.com/Yusufihsangorgel/redis_task_queue) — a small Redis-backed task queue for server-side Dart.
